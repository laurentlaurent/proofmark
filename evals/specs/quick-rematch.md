# Quick Rematch

## Summary
After a head-to-head match, both players can tap Rematch to play again for the same entry fee.

## How it works
1. At the end of a match, both players see a **Rematch** button for 10 seconds.
2. If both players tap it, a new match starts with the same entry fee.
3. If either player leaves or the timer runs out, there is no rematch.
